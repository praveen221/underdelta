01 / WHY

Code generation accelerated.
Understanding didn’t.

Agents can ship more code in an afternoon than a person can responsibly review. The bottleneck is no longer writing—it is building an accurate mental model.

We used tools like Graphify to map repositories for other agents. Useful for machines, yes. But humans need a calmer view: what systems exist, how they connect, and which source lines prove each claim.

Underdelta turns a repository into that view. Not a prettier call graph. Not an AI-generated guess. A product map designed to help you trust what shipped.

02 / PRINCIPLES

Built to earn trust,
not manufacture confidence.

Every visual decision follows one rule: make the repository easier to understand without making claims the code cannot support.

01
⌁

Evidence over invention

Nodes and edges come from the repository. Certainty is marked observed, derived, or inferred. Unknown frameworks stay blank — never hallucinated into a pretty lie.

02
◎

Product story, not symbol soup

Default view collapses modules and functions into systems, pages, APIs, data, and jobs. The map should answer “what did I build?” before anyone opens Details.

03
◇

Twin engines

Capability extracts real stacks. Polish keeps the Beginner walk calm. A feature is not done until the map is golden-locked and cold-readable.

THE ONLY QUESTION

What did I actually build?

Routes, components, databases, migrations, cron, queues, pipelines—connected to the exact file and line that justified them.

03 / REFUSALS

Clarity requires
saying no.
