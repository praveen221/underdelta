# Mindset — 2026-08-15

**Locked direction after comparing both agent reviews.**  
Not a loop. Not a feature list. How we proceed until the next dated file.

---

## Decision

Underdelta is a **typed behavioral model with evidence**, for agents and
humans, **not** a generic code graph and **not** a graph-viewer company.

We enrich a scalable symbol graph (files, symbols, calls). We do **not**
spend years becoming SCIP, Sourcegraph, Greptile, or Graphify.

We copy Graphify’s **install → query** feel. We keep our **ontology**.

---

## What we agreed (do not reopen)

- Symbol graphs scale; we layer semantics on top.
- The moat is roles, impact, evidence, and **explicit unknowns**.
- Viewer and agents consume the **same facts**.
- Freeze framework breadth and major viewer work.
- Viewer is the audit UI. Recurring job is change planning / impact.
- No institutional raise on “we have a graph.” Do not quit either.

---

## What we picked (the 15% split)

| Debate | Locked choice |
|--------|----------------|
| MCP first vs skill first | **Skill + CLI first.** MCP after the three queries prove useful. |
| 20–30 tasks × many repos | **Phase 1:** 8–12 gold questions, **one** real repo, 3 runs. Broaden before we *claim*. |
| Graphify in the first bake-off | **No.** Repo-tools vs Underdelta first. Graphify after the baseline is boring. |
| Ablations immediately | **After** Underdelta beats baseline. |
| Policy + runtime traces | Later. Not this phase. |
| Validation bar | Phase 1: habit and correctness on one repo. Teams / pay / 10pp lift: later. |

---

## Immediate work (this phase only)

1. `underdelta query writes`, `query impact`, `query unknown`.
2. A minimal **agent skill** that must use those commands before grepping.
3. Controlled A/B on **one** real repository (prefer Express RealWorld).
4. Measure: correctness vs gold, invented claims, evidence quality, tokens, time, tool calls.
5. MCP and a wider benchmark **only** if Phase 1 is clearly positive.

Do not start another navigable-graph loop. Do not add adapters because a stack is popular.

---

## How we know Phase 1 worked

On **semantic** questions (who writes this table, what this file affects, what we failed to understand):

- Fewer invented endpoints/resources than baseline, **and**
- Better or equal gold-answer correctness, **and**
- Meaningfully fewer file reads or tokens (order of 25% is a target, not a religion).

Include at least one **trap** question where a symbol graph should win, so we do not lie to ourselves.

If we only save tokens and get worse answers, the agent thesis is not working.
