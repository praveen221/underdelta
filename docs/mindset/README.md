# Mindset

Dated snapshots of **how we think the company should proceed**. Not loop
plans, not architecture specs, not marketing.

| File | Role |
|------|------|
| This README | How to add a day. Pointer to the latest. |
| `YYYY-MM-DD.md` | That day's locked mindset |

**Latest:** [2026-08-15.md](2026-08-15.md) (same-day wording fix: Phase 1 measures trials, not habit; skill may still grep)

## How to use

Each day you want to record a shift, add `docs/mindset/YYYY-MM-DD.md`.

- Write what is **true today**, what we will **do**, and what we will **not**.
- Name disagreements if two views were on the table; pick one.
- Do not rewrite old days. The history is the point.
- Update the **Latest** line in this README when you add a file.

Loop plans stay in `docs/loopplans/`. Product contract stays in
`PRODUCT_MVP.md`. This folder is only judgment over time.
